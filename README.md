# 🏥 ระบบบริหารคลังยา รพ.สต. (JHCIS Drug Stock & Stock Card)

ระบบบริหารจัดการคลังยา นำเข้าไฟล์ Excel รับยาจากโรงพยาบาลแม่ข่ายเข้าสู่ฐานข้อมูล JHCIS (`jhcisdb`) อัตโนมัติ พร้อมคำนวณและแสดงสถานะยา **Drug Stock** เปรียบเทียบกับยอดการจ่ายยาจริงในระบบ JHCIS (`visitdrug`) และแสดงบัญชีคุมยา **Stock Card** รายตัวตามมาตรฐานงานเภสัชกรรมกระทรวงสาธารณสุข

---

## 🌟 ฟังก์ชันหลักของระบบ (Key Features)

### 1. นำเข้าไฟล์ Excel รับยาจาก รพ. แม่ข่าย (Excel Batch Ingestion)
* **รองรับคอลัมน์มาตรฐานจาก รพ.:**
  * `hosdrugcode` (รหัสยา รพ.แม่ข่าย)
  * `tmtid` (รหัสยามาตรฐาน 24 หลัก สปสช. / TMT)
  * `drugname` (ชื่อยา / ความแรง / รูปแบบ)
  * `drugtype` (ประเภทยา เช่น ยาเม็ด, ยาน้ำ, แคปซูล)
  * `lot` (เลขที่ผลิต / Lot No.)
  * `exp.date` (วันหมดอายุ รองรับ พ.ศ. / ค.ศ. / Excel Serial Date อัตโนมัติ)
  * `amount` (จำนวนรับ)
  * `cost` (ราคาทุน)
* **ระบบจับคู่อัจฉริยะ 3 ระดับ (Smart 3-Tier Matcher):**
  1. **ระดับ 1 (100% Match):** จับคู่ด้วย **`tmtid` รหัสมาตรฐาน 24 หลัก** กับทะเบียนยา JHCIS (`cdrug.didstandard`)
  2. **ระดับ 2:** ตรวจสอบประวัติการจับคู่รหัสยา รพ. ที่เคยผูกไว้ (`drug_mappings`)
  3. **ระดับ 3:** ค้นหาชื่อยาที่ใกล้เคียงที่สุด (Fuzzy Name Matching) พร้อมให้เจ้าหน้าที่กดยืนยันเลือกได้
* **บันทึกเข้าฐานข้อมูลของระบบทันที:** เก็บลง `backend/src/data/localdb/receipts.json` (เขียนแบบ atomic + backup .bak) — **jhcisdb ถูกใช้แบบ "อ่านอย่างเดียว" เท่านั้น ไม่มีการเขียนลง JHCIS เด็ดขาด**
* **กันบันทึกซ้ำ:** เลขที่ใบรับซ้ำจะถูกบล็อก (HTTP 409) ป้องกันสต็อกถูกนับเบิ้ล

---

### 2. แดชบอร์ด Drug Stock & แถบตัวกรองสถานะด่วน (Smart Filter Badges)
* 🚨 **ยาเหลือน้อย (Low Stock):** คงเหลือ $\le$ จุดสั่งซื้อ (Min Stock) หรือพอใช้น้อยกว่า 30 วัน
* ⏳ **ยาใกล้หมดอายุ (Near Expiry):** ยาล็อตที่จะหมดอายุภายใน 3 - 6 เดือน เพื่อเร่งระบายยาตามหลัก FEFO
* ⛔ **ยาหมดอายุแล้ว (Expired):** เลยวันหมดอายุ ห้ามจ่ายผู้ป่วย
* 💤 **ยาค้างสต็อก (Dead Stock):** มียาในคลัง แต่ไม่มียอดจ่ายใน JHCIS เกิน 90 วัน
* 🟢 **สต็อกปกติ (Normal):** ยอดและวันหมดอายุอยู่ในเกณฑ์สมดุล
* **ตัวกรองช่วงเวลา:** เลือกดูยอดเคลื่อนไหวตั้งแต่ "เดือนนี้ ถึง เดือนนี้" (คำนวณยอดรับ Excel vs ยอดจ่าย `visitdrug`)

---

### 3. บัญชีคุมยา (Digital Stock Card View)
* แสดงประวัติการเคลื่อนไหวแบบ Real-time: **ยอดยกมา $\rightarrow$ รับเข้า (จากบิล รพ.) $\rightarrow$ จ่ายออก (JHCIS) $\rightarrow$ คงเหลือสุทธิ**
* คำนวณอัตราการใช้ยาเฉลี่ยต่อเดือน (**AMC** - Average Monthly Consumption)
* ประมาณการวันพอใช้ (**Runway Days**)
* แสดง**ยอดคงเหลือราย Lot** โดยตัดยอดจ่ายจาก JHCIS ตามหลัก **FEFO (First-Expired, First-Out) แบบคำนวณอัตโนมัติ** — lot หมดอายุก่อนถูกหักก่อน
* **ยอดยกมาผูกกับวันตรวจนับ:** ระบบแยกแยะว่าผลนับเกิดก่อน/ใน/หลังช่วงงวดที่ดู และคำนวณย้อนกลับพร้อมแจ้งเตือนอัตโนมัติ (ก่อนหน้านี้เป็นจุดที่ทำให้ยอดคงเหลือคลาดเคลื่อน)
* **แสดงยอดติดลบพร้อมเตือน** (ไม่ซ่อนความคลาดเคลื่อน) + รายงาน **Variance** (ยอดนับ vs ยอดคุม)
* **รายการปรับปรุงคลัง:** ตัดจำหน่ายยาหมดอายุ/ชำรุด, ปรับปรุงเพิ่ม/ลด, โอนย้าย, คืนยา รพ.แม่ข่าย — บันทึกในบัญชีคุมได้
* รองรับการกด **"พิมพ์บัตรคุมยา (Print Stock Card)"** ออกกระดาษหรือบันทึกเป็น PDF ตามแบบฟอร์มมาตรฐาน

---

### 4. ระบบยืนยันตัวตนและการเชื่อมต่อ JHCIS
* **Login:** ใช้ชื่อผู้ใช้งานและรหัสผ่านเดิมของเจ้าหน้าที่ในระบบ JHCIS (ตาราง `user` ใน `jhcisdb`) — ออก **session token** (อายุ 12 ชม.) **ทุก API ต้องยืนยันตัวตน**
* **สิทธิ์ผู้ใช้ (Role):** admin (ดูรายชื่อใน `config.json` → `admins`) เท่านั้นที่รีเซ็ตยอดนับ/แก้ตั้งค่า DB ได้
* **Rate limit:** ล็อกชั่วคราวเมื่อพยายาม login ผิด 6 ครั้ง/15 นาที
* **PDPA:** พรางชื่อ/เลขบัตร/PID **ฝั่งเซิร์ฟเวอร์** เป็นค่าเริ่มต้น — เปิดชื่อเต็มต้องระบุเหตุผล และถูกบันทึก audit trail (ม.39) ทุกครั้ง
* **Dual Database Mode:**
  * **Live JHCIS Database:** เชื่อมต่อฐานข้อมูล MySQL/MariaDB ของ JHCIS ผ่านพอร์ต 3333 หรือ 3306 (รองรับภาษาไทย TIS-620 และ UTF-8)
  * **Demonstration Mode (โหมดจำลอง):** มีชุดข้อมูลจำลอง รพ.สต. เสมือนจริงให้ทดลองใช้งานได้ทันที แม้ยังไม่ได้เปิดเชื่อมฐานข้อมูลจริง

## 🚀 วิธีการเปิดใช้งาน (Quick Start)

## 🗄️ สถาปัตยกรรมการเก็บข้อมูล (สำคัญ!)

| ข้อมูล | เก็บที่ | สิทธิ์ต่อ jhcisdb |
|---|---|---|
| ทะเบียนยา, ประวัติจ่ายยา, ข้อมูลผู้ป่วย | `jhcisdb` (MySQL ของ JHCIS) | **อ่านอย่างเดียว (SELECT เท่านั้น)** |
| ใบรับยาจาก รพ.แม่ข่าย (Excel) | `backend/src/data/localdb/receipts.json` | ไม่เกี่ยวกับ jhcisdb |
| ผลตรวจนับยอดยกมา | `backend/src/data/localdb/stock_counts.json` | ไม่เกี่ยวกับ jhcisdb |
| รายการปรับปรุง/ตัดจำหน่าย | `backend/src/data/localdb/adjustments.json` | ไม่เกี่ยวกับ jhcisdb |
| การจับคู่รหัสยา รพ.แม่ข่าย | `backend/src/data/mappings.json` | ไม่เกี่ยวกับ jhcisdb |
| Audit trail (PDPA ม.39, การแก้ยอดนับ) | `backend/src/data/localdb/*.log` + `logs/pdpa_access_audit.log` | ไม่เกี่ยวกับ jhcisdb |

**การสำรองข้อมูล:** สำเนาโฟลเดอร์ `backend/src/data/localdb/` เก็บไว้ที่อื่นเป็นประจำ (ไฟล์ .bak สำรองอัตโนมัติ 1 รอบย้อนหลังเท่านั้น)

**กันข้อมูลเสีย:** ทุกไฟล์เขียนแบบ atomic (tmp → rename) + กู้คืนจาก .bak อัตโนมัติหากไฟล์หลักเสียหาย

## 🏥 การนำไปใช้กับหน่วยบริการอื่น (Multi-Unit)

ระบบไม่ผูกกับหน่วยบริการใดหน่วยหนึ่งแล้ว ตอนติดตั้งหน่วยใหม่:

1. เปิดโปรแกรม → เข้าเมนู **ตั้งค่า** → กรอก: IP/พอร์ต JHCIS ของหน่วย, **รหัสหน่วยบริการ (PCU Code)**, **ชื่อสถานบริการ**, **ที่ตั้ง**, **รพ.แม่ข่าย**
2. ระบบจะ **self-test โครงสร้างฐานข้อมูล** อัตโนมัติ (ตาราง `cdrug`, `visitdrug`, `user`, `visit`, `person` จำเป็น / `drugstorereceive` เสริม) และแจ้งเตือนชัดเจนถ้าขาด
3. **ตรวจสอบการเชื่อมต่อ** แล้วบันทึก → login ด้วยบัญชี JHCIS ของหน่วยนั้น
4. ปีงบประมาณ (1 ต.ค. – 30 ก.ย.) คำนวณจากวันที่ปัจจุบันอัตโนมัติ ไม่ต้องแก้ปีทุกปี

> ⚠️ หากเชื่อมต่อ JHCIS ไม่ได้ ระบบจะ**บล็อกการใช้งานและแจ้งเตือน** (ไม่สลับไปข้อมูลจำลองเอง เว้นแต่เปิด `autoFallbackToDemo` ด้วยตนเอง)
